# Marketing image provenance

The public marketing and authentication surfaces use three local still images:

| File | Current use |
|---|---|
| `public/images/hospitality-hero.jpg` | Homepage hero and public-page fallback |
| `public/images/owner-hero.jpg` | "Pentru proprietari" hero |
| `public/images/auth-hero.jpg` | Authentication layout |

The stills were extracted from the project's pre-existing temporary demo clip,
`public/videos/home-hero.mp4`. That clip was originally sourced from "Video of a
House Interior" by Kindel Media on Pexels (video ID `7578546`) under the Pexels
License. The original video is no longer shipped because the redesigned pages
use optimized static imagery instead.

These images are illustrative and must not be presented as photographs of an
actual BH Group property. They should be replaced with approved, owned or
commissioned BH Group photography before production launch; update this file
when that happens.

Property photographs on `/book/[id]` are uploaded per property through the
existing dashboard flow. They are not part of this marketing-image set, and
their usage rights remain the responsibility of the uploader.
